# Market Risk and Financial Microstructure Project

This repository contains the final project for the Market Risk and Financial Microstructure course.

## Overview

The project analyzes financial returns and price dynamics using empirical data, with a focus on tail risk, price impact, and time-scale effects.

## Market Risk Analysis

- Non-parametric Value-at-Risk estimation using Kernel Density Estimation

 -Expected Shortfall computation and comparison with VaR

- Extreme Value Theory analysis using Pickands’ estimator

- Application to daily Natixis stock returns (2015–2018)

## Market Microstructure and Time-Scale Analysis

- Estimation of Bouchaud’s price impact model (concavity and impact decay)

- Multiresolution correlation analysis using Haar wavelet decomposition

- Study of the Epps effect on FX rates (GBPEUR, SEKEUR, CADEUR)

- Estimation of the Hurst exponent and volatility scaling
